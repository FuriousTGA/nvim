# nvim
My NeoVim Config

# Requirements
- nvim v1.11+
- tree-sitter-cli
- I recommend building from nvim from source I had the tarball shit itself

to use this config 
- move `init.lua` and `after` to `$HOME/.config/nvim` so the paths should be `$HOME/.config/nvim/init.lua` and `$HOME/.config/nvim/after`
